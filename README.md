# TCCFinancas_Casa
Sistema web de finanças domésticas desenvolvido com React, Python e SQLite. Permite gerenciar famílias, membros, permissões, receitas, despesas, parcelas e gastos fixos, além de oferecer relatórios, acessibilidade e interface responsiva.

PC WINDOWS
1. npm install
2. npm run build
3. py backend/server.py
4. Abra http://127.0.0.1:3000
